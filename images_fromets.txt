Regular Use (End Users / Web / Social Media)
7

These are must-support formats for any modern platform:

.jpg / .jpeg → photos, compression-friendly
.png → transparency, UI assets
.gif → simple animations
.webp → modern web compression (smaller size)
.svg → vector graphics (logos, icons)
.bmp → basic bitmap (rare but simple)
.ico → icons (favicons, apps)

👉 If your app doesn’t support these, it’s incomplete.
