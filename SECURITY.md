# Security Policy

## Supported Versions

We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | ✅ Supported       |
| < v0.1  | ❌ Not Supported   |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue. Instead, send an email to security@safetools.space.

We will acknowledge your report within 48 hours and provide a timeline for a fix.

## Security Posture

- **Local-First**: All processing happens in the browser.
- **WASM Sandboxing**: Heavy logic is sandboxed in WebAssembly.
- **Privacy**: No tracking, no uploads.
